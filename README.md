# Dear Data
#  Film & TV 

> A personal data-documentary repository that tracks, categorizes, and reflects upon my media consumption habits over a multi-week period.

##  Repository Structure

The project directory is structured as follows:
```text
├── README.md                  # Project overview and documentation
├── .gitattributes             # Repository tracking configuration
└── Draft/                     # Core project execution directory
    ├── Draft.pde              # Processing Java foundation script
    └── data/                  # Project data folder containing tracking logs and color rules
        └── Genre_mapping.txt  # Genre mapping color profiles
        └── profile.txt        # Dataset glossary
```
 **Dataset:** The complete data entries are compiled inside the repository file

##  Data Collection Methodology

###  Theme Overview: Media Consumption & Screen Culture
* **Objective:** To manually document film and television consumption habits to analyze patterns in genre preferences, and viewing contexts (e.g., streaming platforms vs. cinema).
* **Collection Strategy:** Every scripted media interaction lasting longer than 20 minutes was tracked live. 

###  Tracked Variables
The data captured is structured around the following core metrics:
- **Temporal Markers:** Date
- **Content Metrics:** Title, medium (Film vs. TV Episode), and genre.
- **Viewing Context:** Streamed on a platform or viewed on the big screen
- **Evaluative Metrics:** A subjective personal rating assigned to each film or television episode to measure individual engagement and quality.
